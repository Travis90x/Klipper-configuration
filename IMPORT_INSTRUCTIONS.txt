✅ COME IMPORTARE:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

METODO 1: IMPORTAZIONE VIA TRAKT WEB (se supportato)
1. Accedi a https://trakt.tv
2. Vai a: Impostazioni → Dati (Settings → Data)
3. Cerca opzione "Import" o "Upload"
4. Carica i file JSON:
   - watched-movies-all.json
   - ratings-movies-all.json

METODO 2: IMPORTAZIONE TRAMITE API (Richiede API Key)
Se Trakt non ha opzione di import web, usa lo script:
   
   python3 trakt_api_mapper.py YOUR_API_KEY ./output ./imported
   
   Dove YOUR_API_KEY è la tua chiave da https://trakt.tv/oauth/authorize/

METODO 3: IMPORTAZIONE MANUALE
1. Apri watched-movies-all.json in un editor di testo
2. Copia i dati
3. Carica manualmente in Trakt tramite l'app o il web
